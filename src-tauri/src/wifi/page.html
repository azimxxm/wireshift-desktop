Hammasi Mac'ga saqlandi

Tugaguncha shu sahifani ochiq qoldiring va ekranni o'chirmang. Uzilib qolsa — sahifani yangilang va fayllarni qayta tanlang: yetib kelgan qismlar qayta yuborilmaydi.

Zip qilib olish
Rasmlar ilovasiga saqlash
  1. Hammasini olish → fayllar birma-bir Files → Downloads papkasiga tushadi
  2. Downloads'da Select → kerakli fayllarni belgilang → Share → Save N Items
  3. Hammasini bitta faylda olmoqchi bo'lsangiz — Zip qilib olish (Files'da bosilganda papkaga ochiladi)
  4. Bitta rasm: nomini bosib oching, ustiga uzoq bosing → Save to Photos

Rasm ustiga bossangiz belgilanadi — faqat tanlanganlar olinadi. Bitta faylni «Olish» bilan olsa ham bo'ladi.

Yuklashni to'xtatish: brauzerning yuklashlar ro'yxatida (↓ belgisi) faylning ✕ tugmasini bosing. Zip to'xtatilsa, Mac uni «Bekor qilindi» deb ko'rsatadi.
